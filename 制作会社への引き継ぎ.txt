株式会社On Your Mark｜サイトリニューアル版 引き継ぎ資料
================================================================

■ このデータについて
・リニューアル版サイト一式（静的HTML）です。WordPress等のCMSは使っていません。
・一般的な静的サイト構成で、HTML/CSS/JS/画像が分離されています。CSS/JS/画像は assets/ 配下にまとめており、既存サイトのファイルと名前が衝突しないようにしています。通常のコードエディタとFTPで更新できます。

----------------------------------------------------------------
■ フォルダ構成（更新のしかた）
----------------------------------------------------------------
  index.html ほか各ページ … ページごとの本文。文言を直すときは該当ページのHTMLを編集
  assets/css/style.css     … 全ページ共通のデザイン。色・余白・レイアウトはここ1箇所で全ページに反映
  assets/js/main.js        … 全ページ共通の動作（ナビ開閉・スクロール表示・フォーム・求人/ニュース描画）
  assets/images/           … 画像ファイル（差し替えは同名ファイルを上書きするだけ）
     logo.webp（ヘッダー/フッターロゴ） logo-hero.webp（TOP大ロゴ）
     main-visual.webp（TOPメイン人物） famfam-cafe.webp（就活カフェ店内）
     whiteboard.webp（三者モデル） startline.webp（会社概要・全幅画像）
  docs/                    … 配布PDF（OYM_service-guide.pdf＝教育機関向けサービス案内／OYM_travel-terms.pdf＝旅行業約款）
                             ※ファイル名を半角英数にしています（FTP転送時の文字化け防止）。
                               利用者に見えるダウンロード名は form/config.php の download_name で日本語を指定します。
  favicon.ico / favicon-32.png / favicon-48.png / apple-touch-icon.png / ogp.png … アイコン・OGP画像
  sitemap.xml / robots.txt … SEO用

※ ヘッダー・フッターは各ページに記述されています（静的HTMLの標準）。ナビ項目を変える場合は全ページ分を同様に修正してください。

----------------------------------------------------------------
■【重要】「公開ページ」と「非公開ページ」があります（意図した設計です）
----------------------------------------------------------------
●公開ページ（検索インデックス対象。sitemap.xml に収録済み）
  index / service-school / service-business / service-students / company /
  travel-terms / contact / download / privacy
●非公開ページ（noindex設定済み。ナビ・sitemapには載せていません）
  jobs（求人一覧＝「個別紹介」の案内ページ。一般公開の一覧なし）
  job-detail（学校・企業ごとに専用URL ?id=◯&key=◯ で渡す限定公開求人用）
  news / news-detail（クローズド運用。TOP・フッターからリンクなし）
  thanks / dl-thanks / 404（性質上の非公開）
●仮（サンプル）データ
  assets/js/main.js 内の求人（OYM_JOBS）・ニュース（OYM_NEWS）はダミーデータです。非公開ページ内だけに存在し、
  公開ページには表示されません。本番では実データに置き換える／不要なら削除してください。

----------------------------------------------------------------
■【要対応1】設置・ドメイン
----------------------------------------------------------------
・フォルダごとサーバーのルートに設置し、index.html をトップにしてください。常時SSL（https）化をお願いします。
・HTML内の正規URL（canonical）・OGP・sitemap.xml・構造化データは「https://oym.co.jp/」前提です。
  公開ドメインが異なる場合は「https://oym.co.jp/」を実ドメインに一括置換してください。
・公開後、Google Search Console に sitemap.xml を登録してください。

----------------------------------------------------------------
■【要対応2】フォーム（最重要）※実装済み・サーバー設定のみ残
----------------------------------------------------------------
※この項目は対応済みです。詳細は同梱の「フォーム設置手順.md」を参照してください。

・お問い合わせ（contact.html）・資料ダウンロード（download.html）は、実際に送信できる状態になりました。
  form/send.php がメール送信・入力検証・自動返信・CSV記録を行います。送信先：contact@oym.co.jp。
・スパム対策は、ハニーポット／時間トラップ／同一IPの連投制限が標準で有効です。
  reCAPTCHA v3 も設定だけで有効化できます（assets/js/config.js と form/config.php にキーを入れる）。
・送信先の切り替えは assets/js/config.js の endpoint 1行だけです。
  WordPress（Contact Form 7）やFormspree等に寄せる場合も、ここを差し替えれば動きます。
・資料ダウンロードは、フォーム送信後にサーバーが発行する署名付きワンタイムURL
  （form/download.php、有効期限1時間）経由で渡す形にしました。
  docs/ 配下のPDFは .htaccess で直アクセスを禁止しているため、フォームを通さずには取得できません。

●サーバー側で必要な作業（これだけ残っています）
  1. form/config.sample.php を form/config.php にコピーし、送信先と token_secret を設定
  2. 送信元ドメインに SPF（できれば DKIM / DMARC）を設定 ※これを省くとメールが迷惑メール扱いになります
  3. .htaccess はリポジトリに含まれ、デプロイで自動設置されます（常時SSL・カスタム404・セキュリティヘッダ）
  4. form/.htaccess と docs/.htaccess の転送漏れに注意（FTPソフトの隠しファイル表示設定を確認）
